# Smart File Organizer 📁

A simple Python automation tool that automatically organizes files into folders based on their file types.

## What it does

The script scans the Downloads folder and automatically sorts files into:

- Images
- Documents
- Videos
- Audio
- Archives
- Other files

## Why I built it

I wanted to explore how Python can be used to automate simple repetitive tasks. Organizing downloaded files manually is a small task, but it is something people repeatedly do.

This project helped me practice working with file paths, file extensions, loops, dictionaries, and file-system automation.

## Technologies

- Python
- pathlib
- shutil

## How it works

1. Scans the Downloads folder.
2. Detects each file's extension.
3. Creates the appropriate category folder if needed.
4. Moves the file automatically.
5. Keeps unsupported file types inside an "Other" folder.

## What I learned

This project helped me understand how small scripts can solve everyday problems and introduced me to practical automation with Python.
